## 데이터와 반복 색인

입력 200건 / 메타데이터 색인 200건. 메타데이터 색인 두 차례 실행 모두 변경 0건, 색인 건수 200건 유지.

등록 원문 첫 실행은 Spot 1청크, Ameca 2청크, Pepper 3청크 저장·갱신. 같은 원문을 재실행했을 때 세 모델 모두 변경 0건. CLI 검증 종료 당시 외부 청크는 1,647개. 이후 브라우저의 Wikidata 추가 수집으로 1,648개가 됐다. 두 수치는 서로 다른 시점이다.

원문은 기존 위키백과 본문 캐시에서 복원했으며 전문 PDF나 제조사 공식 사양으로 표시하지 않는다.

| 같은 원문 | 1000자 / 중복 200자 | 500자 / 중복 100자 |
|---|---:|---:|
| 스팟 (로봇) | 1청크 | 2청크 |
| 아메카 (로봇) | 2청크 | 3청크 |
| 페퍼 (로봇) | 3청크 | 5청크 |

두 설정으로 동일 텍스트를 실제 분할해 비교했다. 운영 DB의 청킹 설정을 변경해 재색인한 비교는 아니다.

## 질문·답변과 처리 시간

아래 시간은 추가 온라인 수집을 끄고 등록 원문·기존 DB로 실행한 전체 파이프라인 시간이다. LLM·임베딩은 실제 GMS를 사용했다.

| 질문 | 시간 | 답변 검토 |
|---|---:|---|
| Spot의 현장 활용 사례 | 17.35초 | 논문 초록의 연구·시험 사례와 검증되지 않은 메타데이터를 구분 |
| Ameca 개발사와 활용 목적 | 11.31초 | Engineered Arts와 HRI 플랫폼을 위키 본문으로 인용 |
| Spot의 250도 운용 인증번호 | 14.13초 | 자료에 인증번호가 없어 확인불가로 답함 |
| Spot을 250도 배관 구역에 투입 가능한지 | 12.98초 | 확인불가 판정, 온도 한계·노출 시간 등 미확인 조건 제시 |

근거가 주장을 실제로 뒷받침하는지는 위 대표 답변을 직접 검토했다. 자동 검사는 빈 응답과 인용 번호 범위만 판정한다. 질문 전체에 대한 사실 정확성 자동 점수는 산출하지 않았다.

세 번째 실제 답변의 `[근거 1–5]`가 기존 파서에서 인식되지 않는 문제가 발견됐다. 범위형 인용을 지원하도록 수정했고, 저장된 네 답변을 수정 파서로 재검사해 인용 수 5/1/5/3개, 잘못된 인용 번호 없음으로 확인했다. 원래 실행값과 수정 후 재검사값은 JSON에 구분해 보존했다.

같은 질문의 검색어 캐시 재사용 로그를 확인했다. 첫 질문과 캐시 질문의 전체 처리 시간을 동일 조건으로 쌍 비교하지는 않았다.

## Top-k·MMR 비교

같은 Spot 질문에서 실제 벡터 검색을 수행했다. 메타데이터 1건은 Top-k와 별도다.

| 방식 | 외부 Top-k | 전체 근거 수 | 관찰 |
|---|---:|---:|---|
| similarity | 2 | 3 | 강화학습 논문·벽돌 쌓기 논문 |
| mmr | 2 | 3 | 강화학습 논문·스팟 위키 원문 |
| similarity | 5 | 6 | 강화학습 논문의 서로 다른 청크가 2개 포함 |
| mmr | 5 | 6 | 해당 논문의 두 번째 청크 대신 스팟 원문 포함 |

이 질문에서는 MMR이 문서 구성을 다양하게 했다. 모든 질문에서 품질이 좋아진다고 일반화하지 않는다. 검색된 청크 원문은 live_results.json의 search_comparison에 있다.

LangGraph의 실제 노드 목록은 `__start__`, `retrieve`, `generate`, `__end__`다. 처리 노드는 두 개다.

## 외부 검색의 실제 제약

브라우저에서 추가 수집을 켠 기존 경로를 실행한 결과 Reddit 403, ROS 404, Google Patents 503을 확인했다. Wikidata는 Ameca 검색에서 2개 후보를 반환했으며 최종 선별 후 1청크가 저장됐다. 외부 수집 전체가 성공했다고 기록하지 않는다.

앱은 기본적으로 저장된 문서와 등록 원문으로 답하고 필요할 때 ‘외부 자료 추가 검색’을 켜도록 변경했다. settings.json의 출처 목록과 사전 수집 CLI는 유지한다.

## 남은 제출 조건

1. 운영자 실제 공개 연락처 또는 프로젝트 URL을 ROBOTLAB_USER_AGENT에 입력.
2. robots_data.json 최초 출처·작성 방식과 모델별 세대·사양을 확인.
3. 미등록 모델 원문을 확보해 자체 문서 등록 범위를 확대. 현재 200종 모두에 대해 원문이 준비된 것은 아님.
4. 다른 교육생이 상호 검증하고 이름·날짜·판정을 추가.
5. 공개 배포할 기존 초록·RSS 등은 자료별 이용 조건을 확인. F2015 RAG 전후 비교는 선택 과제로 미구현.
